# لعبة MAFIA ROOM

لعبة مافيا جماعية عربية تعمل من متصفح الجوال، وتدعم غرفاً خاصة بكود من 5 إلى 8 لاعبين.

## تشغيلها على جهازك
1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط المشروع.
3. افتح الطرفية داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000`.

## نشرها على الإنترنت
ارفع مجلد المشروع إلى مستودع GitHub، ثم أنشئ Web Service على منصة استضافة تدعم Node.js (مثل Render).
- Build Command: `npm install`
- Start Command: `npm start`
- اجعل الخدمة تستمع إلى المنفذ الذي توفره المنصة (التطبيق يقرأ `process.env.PORT`).
بعد النشر، شارك رابط الخدمة مع أصحابك. كل لاعب يفتح الرابط من هاتفه.

## توزيع الأدوار
- 5 لاعبين: مافيا واحدة، محقق، و3 مواطنين.
- 6 لاعبين: مافيا واحدة، محقق، طبيب، و3 مواطنين.
- 7–8 لاعبين: مافيا اثنتان، محقق، طبيب، والباقي مواطنون.

## ملاحظات النسخة الأولية
- الخادم يدير الغرف والأدوار والأحداث في الذاكرة؛ إعادة تشغيل الخدمة تنهي الغرف الحالية.
- يحتاج اللاعبون إلى البقاء متصلين أثناء الجولة؛ إعادة الاتصال واستعادة الدور غير مفعّلين بعد.
- لا تشاركوا كود الغرفة إلا مع أصدقائكم.
- هذه نسخة أولية قابلة للتطوير وليست منتجاً أمنياً أو تنافسياً.
